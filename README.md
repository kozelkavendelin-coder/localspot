# LocalSpot 📍

Mobilní aplikace pro objevování lokálních podniků v České republice.

## Obrazovky
- 🗺️ **Mapa** — podniky s barevným hodnocením
- 🔍 **Hledat** — filtrování podle kategorie, otevírací doby a vzdálenosti  
- ❤️ **Oblíbené** — uložené podniky
- 💬 **Diskuze** — lokální sociální feed

## Tech Stack
- React Native + Expo
- React Navigation (bottom tabs)

## Spuštění
```bash
npm install
npx expo start
```
